# Lyto — система оплаты (спека под реализацию с CLI)

> Владелец: Arystan (Polar на нём). Внедряется вместе с CLI-лончем.
> Модель: **Free (по умолчанию) + Trial 3 дня (opt-in, с картой, авто-конверсия в Pro) + Pro ($15/мес)**. CLI = BYO-key.

---

## 0. Принцип

Три состояния, у каждого своя работа:
- **Free (по умолчанию, навсегда)** — все стартуют здесь. Никаких авто-триалов при регистрации.
- **Trial (3 дня, opt-in с картой)** — включается, только когда юзер сам жмёт «оформить Pro» и вводит карту. По истечении 3 дней — **автосписание → Pro**. Отмена в любой момент → фолбек на Free.
- **Pro ($15/мес)** — дорогие мышцы (research, облако, CLI, мессенджеры).

Дорогие примитивы = твоя COGS-нагрузка → за пейволлом. CLI = ключ юзера → почти нулевая себестоимость → самый маржинальный тир.

**Главная граница тиров (архитектурная):** **Free = «работает в открытом браузере», Pro = «работает, когда тебя нет».** Всё, что исполняется в фоне или доставляется в мессенджер (мессенджер-бот = фоновый агент при закрытом ПК / CLI при открытом; scheduled-таски; research), физически требует Pro-примитивов → на Free его нет. Free = только живой экстеншен. Это и чистый биллинг, и сильный повод платить.

## 1. Тиры и entitlements

| Возможность | Free | Trial (3 дня) | Pro |
|---|---|---|---|
| Модель чата | gemini-2.5-flash | gemini-3-flash | gemini-3-flash |
| Сообщений/день | **10–15** (дневной сброс) | как Pro | ~400/мес (ref) |
| Память (identity, факты) | ✅ полная | ✅ | ✅ |
| Research | ❌ | ✅ (лимит как Pro) | ✅ ~7 (ref) |
| Облачный фоновый агент (= то, что обслуживает мессенджеры при закрытом ПК) | ❌ | ✅ | ✅ |
| CLI (десктоп-агент, BYO-key; обслуживает мессенджеры при открытом ПК) | ❌ | ✅ | ✅ |
| Мессенджеры (WA/TG) | ❌ (нужен фоновый агент/CLI → Pro) | ✅ | ✅ |
| Scheduled / фоновые таски | ❌ (исполнять и доставлять некому → Pro) | ✅ | ✅ |
| Публичный шаринг `/s/` | ✅ | ✅ | ✅ |
| Генерация файлов (docx/pdf/xlsx) | базово в лимите, в сессии | ✅ | ✅ |

**Дневной лимит Free — почему дневной, а не месячный:** дневной сброс создаёт привычку возвращаться и режет пиковую стоимость; месячный юзер выжигает за присест и отваливается на месяц. Точное число (10 или 15) — от «сколько сообщений до первого вау».

## 2. Триал — как должно работать

**Модель: Free по умолчанию → opt-in триал с картой → авто-конверсия в Pro.**

**Флоу:**
1. Новый юзер регается → сразу **Free** (2.5-flash, лимиты). Никакого триала по умолчанию.
2. Юзер хочет Pro → жмёт «оформить подписку» → **вводит карту** → стартует **3-дневный триал** с полным Pro-доступом.
3. Через 3 дня → **автосписание $15 → Pro**. (Стандартный Polar trial-with-payment-method.)
4. Отмена (в триале или в подписке) → в конце периода **фолбек на Free**, доступ и данные сохраняются.

**Критично для Polar:**
- Триал = нативный Polar trial **с обязательным payment method**. По окончании — авто-charge, юзер становится платным Pro.
- На отмену/неоплату (webhook `subscription.canceled` / `subscription.updated` → `canceled`) → переключить entitlement на **Free**, НЕ терять доступ/данные. Не пейволл, а мягкий фолбек.
- Entitlement хранится у нас; Polar = источник статуса подписки.

**Анти-абьюз:** триал по аккаунту (email + желательно device/fingerprint), чтобы не пересоздавали ради повторных триалов.

**Как юзер щупает магию:** через сам **3-дневный триал** — это и есть механизм «попробовать всё». Отдельного free-сэмплера нет (дать Free-юзеру облачную задачу нельзя — это Pro-примитив, сломало бы границу тиров). На Free — только **визуальный тизер** запертого (заблюренный превью брифа с данными юзера под замком): показываем, но не исполняем.

## 3. Апселл (когда показываем Pro)

Показывать upgrade-CTA в момент упора в стену, а не рандомно:
- Исчерпал дневной лимит сообщений.
- Нажал Research / облачный агент / CLI на Free.
- Тапнул фичу, которая была в триале, после даунгрейда («ты это уже пробовал — верни»).

Формулировка апселла: не «лимит исчерпан», а «верни мышцы: research, агент в облаке, CLI на своей машине — $15/мес».

---

## 4. CLI-гейтинг (вместе с лончем)

- Установщик отдаётся **только при активной подписке** (Trial или Pro). Free — нет.
- Проверка прав на: pairing, artifact-доступе, WS-подключении.
- **BYO-key:** ключ модели вводит юзер локально, запросы идут напрямую провайдеру → наши токены не тратятся. Для нас CLI = стоимость почти ноль, поэтому гейтим как силовой тир, а не из-за COGS.
- На старте: Trial (3 дня) даёт CLI-доступ → хороший хук распробовать десктоп-агента, потом Pro.

---

## 5. Юнит-экономика (для контроля)

- Pro worst-case (400 сообщений + 7 research): ~$5–6. Средний активный: ~$2. С кэшем: ~$0.5–1.
- Research дорогой: $0.10–0.30 за штуку → только Pro.
- Free на 2.5-flash без research: центы ($0.1–0.3/мес).
- **Мониторить cache-hit rate как метрику.** Вся дешёвая экономика висит на кэше (Gemini context caching ~4× на кэшированный вход). Если тихо просядет — стоимость ×4 на самой массовой когорте (Free). Поставить алерт.
- Google for Startups (после ангела) — кредиты на Gemini/Vertex субсидируют COGS. НО не проектировать постоянную экономику под временные кредиты: Free должен быть устойчив и без них.

## 6. Чек-лист реализации

- [ ] Продукты/цены в Polar: Pro $15/мес с trial 3 дня
- [ ] Trial **с обязательной картой** (Polar trial-with-payment-method) → авто-charge на 3-й день
- [ ] Webhook на отмену/неоплату → downgrade entitlement на Free (сохранить доступ/данные, не пейволл)
- [ ] Entitlement-слой у нас: Free / Trial / Pro → гейтинг фич по таблице §1
- [ ] Дневной счётчик сообщений на Free (сброс в полночь по таймзоне юзера)
- [ ] Гейт Research / облако / CLI по entitlement

- [ ] Апселл-CTA на упор в стену
- [ ] Анти-абьюз триала (email + fingerprint)
- [ ] Алерт на cache-hit rate
