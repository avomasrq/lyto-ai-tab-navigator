# Lyto — core narrative для питча (EF / YC)

## Стержень (одна фраза)

**Один агент, одна память, одна личность — везде, где ты работаешь.**
Не три продукта, а одно существо с одним мозгом, которое дотягивается до тебя
из браузера, из облака при закрытом ноуте и с самой машины.

Общий слой под всеми поверхностями: **одна память, одни scheduled-таски, одни MCP,
один сейф кук и креденшелов.** Три поверхности (экстеншен / облако / CLI) — это руки,
тянущиеся в разные места. Мозг и идентичность — одни.

- Экстеншен упёрся в песочницу вкладки → облако продолжает при закрытом ноуте →
  CLI берёт полную власть на локальной машине с твоим реальным Google-профилем.
- Технически сердце — **непрерывность идентичности через куки/креды**:
  экстеншен снял сессию → облачный браузер уже залогинен → CLI поднимает браузер
  с твоим локальным профилем. Один и тот же «ты» в трёх вычислительных средах.

Всё остальное (Focus, Deep Research, Jarvis, файлы, мессенджеры) — это способности
**одного** существа, а не отдельные фичи.

---

## Wedge против OpenClaw

OpenClaw (150k+ звёзд на GitHub, создателя забрал OpenAI) уже **доказал спрос**:
люди хотят личного агента, который живёт в их чате и рулит их машиной.

Но у него жёсткий потолок: **надо self-host'ить.** Поэтому им пользуются только
технари и соло-фаундеры — не потому что продукт для них, а потому что больше никто
не может его завести и няньчить.

> OpenClaw заставляет платить полную цену установки на первом шаге. Мы — нет.
> 80% ценности берёшь через экстеншен с нулевым сетапом; на терминальный тир
> поднимаешься, только когда реально нужна полная власть над машиной.

## Лестница трения (снимает страх «три продукта вместо одного»)

| Поверхность | Цена входа | Досягаемость |
|---|---|---|
| **Экстеншен** | ноль (ставишь из стора) | одна вкладка, песочница браузера |
| **Облачный агент** | ноль локального сетапа | весь веб на нашей стороне, работает при закрытом ноуте |
| **CLI / десктоп-агент** | установщик + команда + ключ (осознанный опт-ин) | весь ПК (shell) + весь веб (Playwright), твой реальный профиль |

Честно: терминал у CLI есть. Но не на входе, и это не self-host с девопсом —
установщик под подписку, а не Kubernetes, который надо держать живым 24/7.

---

## Moat = must-have (это один и тот же слой)

Must-have живёт не в фиче (её копируют за неделю), а в **переключательной стоимости.**
Она вся в общем слое: логины, куки, память, повторяющиеся задачи, MCP — в одном месте,
следуют за тобой по всем средам. Уйти = переподключить всё заново везде. Это цемент, не витамин.

---

## Ответ про доверие (к нему давят сразу)

Главная ценность и главный риск — **один и тот же слой**: общий сейф кук и креденшелов.
Ответ должен звучать так же уверенно, как сам питч:

- Шифрование **AES-256-GCM**, права файлов `0600`, TTL на секреты.
- **BYO-key** — ключ модели у пользователя, запросы напрямую провайдеру.
- Редакция секретов из логов и памяти, отзыв доступа/шаринга в один клик.
- Изоляция данных пользователей (RLS), каскадное удаление аккаунта.

## Что реально нести на EF/YC (не путать с фичелистом)

1. **Founder + скорость** — solo-технарь довёл до работающего мультиканального продукта.
2. **Traction** — хоть один пользователь, который не уходит (retention > теории).
3. **Wedge** — «OpenClaw для тех, кто не умеет self-host'ить», один острый ICP.
4. **Why-now** — модели стали достаточно сильны, спрос доказан OpenClaw, но hosted+zero-setup ниши нет.
